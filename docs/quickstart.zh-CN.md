# 财务报表勾稽工具：第一版使用说明

本工具在本机运行。当前接收整理好的财报、TB 和附注数据；原始 Word、PDF、Excel 自动读取尚未接入。

## 启动与试用

在项目目录运行 `python3 -m tieout serve`，然后打开 <http://127.0.0.1:8765>。

1. 点击“加载演示数据”。示例全部为虚构数字。
2. 查看 TB 科目对应的报表项目、列报符号及确认依据。
3. 填写复核人员和设置说明，选择全局容差（默认 0，上限 50,000）。
4. 点击“运行勾稽检查”。预设 PPE 附注差异为 15,000。
5. 将全局容差改为 15,000 后重新运行；该差异会变为 `WITHIN_TOLERANCE`，仍然列为异常。
6. 在单项容差中给 `N-01` 输入 0，再次运行；该规则重新按精确匹配判断。

## 附注编号如何处理

系统不会认为 Note 3 永远是现金或固定资产。它读取附注主题和表格行标题，使用
`rules/note_matchers.json` 中的中英文词汇寻找对应项目。编号只出现在来源记录里。

- 唯一、口径一致的候选：自动对应并比较。
- 多个候选或期间、币种、报表范围不一致：待复核。
- 没找到对应内容：未测试，不当作通过。
- 人工指定：选择具体附注行，填写理由，重新运行；选择会保留在本次记录中。

目前识别基于可配置标题及行项目别名，不是任意语言或任意版式识别。
收到不同公司的真实草稿后，应验证表格提取、同义标题、比较年度和总额/净额区分。

## 导出与留痕

可下载 Excel、异常 CSV 和完整 JSON。JSON 保存输入、规则、附注匹配配置、容差、
来源、复核人及运行时间，是完整的追溯记录。Excel 金额按文本保存，避免丢失精度。
每次运行另外保存在本机 `audit-runs/`；该目录默认不进入 Git。

`WITHIN_TOLERANCE` 不表示数字完全一致。容差是勾稽阈值，不是审计重要性水平。
姓名为使用者填写，记录支持追溯，但目前不提供身份认证或防篡改存储。
